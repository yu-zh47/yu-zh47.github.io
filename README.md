# Yue Zhao 的个人札记

网站地址为 [yu-zh47.github.io](https://yu-zh47.github.io/)。GitHub Pages 会在 `main` 分支更新后自动发布。

## 写下一篇

在 GitHub 打开 [文章目录](_posts/)，选择 **Add file → Create new file**。文件名用日期和英文短名，例如 `2026-11-20-reading-notes.md`。把下面几行放在开头，空一行后直接写正文。

```markdown
---
title: "文章标题"
topic: 随笔
description: "在首页显示的一句摘录。"
---

第一段正文。

## 小标题

下一段正文。
```

点 **Commit changes** 保存到 `main`。首页会按日期列出文章。文件名里的英文短名决定文章网址，例如上面的文章会发布到 `/writing/reading-notes/`。修改标题时可以保留原来的文件名，已分享的链接就能继续使用。
